# Portfolio Website — source evidence

The website project is evidenced by the actual files included in this portfolio package:
- `index.html`, `about.html`, `projects.html`, `skills.html`, `work-experience.html`, `cv.html`, `contact.html`, `fravara-case-study.html`, `wordle-ai-case-study.html`, `local-ai-case-study.html`, and `portfolio-website-case-study.html`.
- `css/style.css` — shared design tokens, responsive layout, dark-mode tokens, cards and animation styles.
- `js/script.js` — theme persistence, scroll-progress update, navbar scroll state, page loader, Intersection Observer reveal, counters and progress animation behaviour.

The supplied `Requirements Table.md` also records the original project self-assessment. This portfolio update does not treat that self-assessment as an independent external validation.

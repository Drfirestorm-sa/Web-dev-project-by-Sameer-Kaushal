Building a multi-page website with a shared design system

I developed this portfolio to present my work, skills and experience in one place. It uses a shared stylesheet and JavaScript file so that navigation, visual styling and interactions stay consistent across the pages.

11
HTML pages in the current portfolio package, including individual project case studies.

My contribution

  • Structured the site into separate pages for introduction, projects, skills, work experience, CV and contact details.
  • Built the page layouts with HTML and Bootstrap, then styled them through a shared CSS system.
  • Implemented JavaScript interactions for the theme switch, scroll progress, navigation state and animated content reveals.
  • Added dedicated project case studies and a downloadable CV.

Technologies

HTMLCSSJavaScriptBootstrap

A shared stylesheet and script reduce duplicated code and make common design changes easier to manage.

Features implemented

Theme and accessibility preferences

Light/dark theme toggle with saved preference and system preference fallback.

Navigation and scrolling

Responsive navigation, scroll-progress indicator and back-to-top control.

Motion and feedback

Page loader, scroll reveals, staggered cards, animated counters and progress indicators.

Reusable page structure

Shared header, footer, typography, colour tokens and card styling across pages.

A challenge I worked through

Because several pages share the same CSS and JavaScript, a change to navigation or theme styling can affect the whole site. I worked through issues with dark-mode contrast and navigation readability, then checked the shared rules across the pages.

This reinforced the importance of reusable styles, consistent page structure and testing both theme states rather than checking only the homepage.
